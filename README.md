# 🏢 ESI - Sistema Imobiliário Completo

Sistema completo para gestão de imobiliárias, inspirado nas melhores funcionalidades do mercado como Apresenta.me.

- Acompanhamento de investimentos
- Gestão de faturas e cartões
- Relatórios financeiros detalhados

### 💬 **Apre.chat** - Sistema de Chat Inteligente
- Atendimento ao cliente em tempo real
- Chat com agentes e bot inteligente
- Videochamadas integradas
- Histórico completo de conversas
- Respostas rápidas e templates

## 🛠️ Tecnologias

- **Frontend**: React 18 + TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Components**: Shadcn/UI
- **Icons**: Lucide React
- **Routing**: React Router DOM
- **State Management**: React Hooks

## 🚀 Instalação

```bash
# Clone o repositório
git clone https://github.com/jefferson-esi/sistema-imobiliario.git

# Entre no diretório
cd sistema-imobiliario

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

## 📱 Acesso

Após iniciar o servidor, acesse `http://localhost:5173`
